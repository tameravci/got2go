Bathroom emergency? Need Wi-Fi? Crowdsourced codes for Seattle coffee shops.

How to find a code

  1. Tap Find Nearby (the crosshair button on the map). Every shop within 0.3 miles drops a pin.
  2. Pin colors: both Wi-Fi bathroom nothing yet
  3. Tap any pin to grab the codes — or add yours to a gray pin so the next person finds it.
  4. Upvote codes that work. Downvote stale ones.
