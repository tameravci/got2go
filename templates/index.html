Bathroom emergency? Need Wi-Fi? Crowdsourced codes for Seattle coffee shops.

How to find a code

  1. Allow your location. The map zooms to the shops around you. Gray pins show shops with no code yet.
  2. Pin colors: both Wi-Fi bathroom public restroom nothing yet
  3. Tap any pin to grab the codes. Add yours to a gray pin so the next person finds it.
  4. Tap 👍 if a code worked or 👎 if it didn't. That keeps the codes fresh.
